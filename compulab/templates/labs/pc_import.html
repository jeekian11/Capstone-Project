Import Computers

Bulk-add PCs from a CSV or Excel file instead of one at a time.
File format

Your file needs a header row with these columns — Lab and PC ID are required, while the remaining columns are optional.

Lab PC ID IP Address Status
Lab 01 PC01 192.168.1.11 Available
Lab 01 PC02
  • The lab name must already exist under Manage Labs — rows with an unknown lab are skipped.
  • Leave IP Address blank if you don't know it yet; it just won't be included in automatic status checks.
  • Leave Status blank to default to "Offline". Valid values: Available, Offline, In Use, Under Maintenance, Has Issue.
  • A PC ID that already exists in that lab is skipped, not overwritten.
  • Accepted formats: .csv or .xlsx.
